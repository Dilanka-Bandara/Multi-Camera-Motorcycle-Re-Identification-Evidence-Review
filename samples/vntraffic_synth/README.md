# VnTraffic synthetic camera sample

Derived from Vehicle Tracking Dataset, Thi-Nhung Le and contributors (2026). Video source credited by the dataset authors to HTV, Hanoi Radio and Television Station. Licensed CC BY 4.0. Source and attribution: https://zenodo.org/records/18195750

Changes include left/right overlapping crops, delayed Camera B, resize, colour/gamma changes, blur and JPEG degradation, followed by H.264 downscaling. The source contains 17 seconds, so this sample retains that content duration; B includes a documented 18-second blank delay. The annotations supply identity boxes without class labels. This pair derives from one view.
