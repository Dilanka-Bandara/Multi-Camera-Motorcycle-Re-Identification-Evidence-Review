## Limits that remain visible in the results

- The learned verifier uses fourteen calibration pairs, only five positive.
  No GT-mapped held-out query was accepted; precision is undefined and recall
  is zero. Threshold combinations tied at zero accepted F1.
- The original RoundaboutHD baseline has one accepted unmapped query; its
  correctness is unknown and it is excluded from scored evaluation. This does
  not support a claim that the system makes no false matches.
- Data splits group annotated query identities but share candidate galleries;
  they are not separate-camera generalization tests. Assignment is replayed
  independently within each split. Neural models are pretrained, not retrained.
- A fixed non-overlapping transit assumption can reject simultaneously visible
  vehicles. Timing rejection alone does not prove different physical identity.
- VnTraffic supplies only 17 seconds of source footage and no class labels;
  its sample duration is a documented deviation from the approximately 60 s
  requested by the guide. RoundaboutHD's SCT class IDs were not assumed to be
  cross-camera IDs, so motorcycle-subset accuracy remains unavailable.
- The demo is a local deliverable under ignored `data/`, not a Git video asset.
  It includes local RoundaboutHD review imagery; the inspected dataset card
  did not declare a redistribution license. Only attributed CC-BY VnTraffic
  samples under `samples/` were committed as videos.

## Rebuilding the local demo

`docs/demo_script.md` specifies the presentation sequence. `scripts/build_demo.py`
assembles the captured UI sequences and evidence screenshots with captions:

```sh
python scripts/build_demo.py --capture data/demo/capture --out data/demo/render-next
```

Use a fresh output path. Browser capture inputs remain local in `data/demo/capture`;
they are not generated by model inference and are not fabricated application views.
